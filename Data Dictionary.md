# Data Dictionary

This document defines the normalized input structure expected by the active
analysis scripts in the revised TAD-PDAC repository.

Patient-level clinical data are not distributed in the repository because of
participant privacy and ethical restrictions.

RNA-sequencing data generated in this study are available under controlled
access through the European Genome-phenome Archive under accession
`EGAS00001007212`, and whole-genome sequencing data under accession
`EGAS00001007211`.

## 1. `data/clinical_data.xlsx`

Used by:

- `01_survival_analysis.R`
- `05_tcell_adjusted_models.R`

One row per patient; current cohort n = 162.

| Column | Type / coding | Definition |
|---|---|---|
| `os_time` | numeric, months | Time from surgery to death/censoring |
| `os_event` | 0/1 | 1 = death from any cause |
| `css_event` | 0/1 | 1 = PDAC death; non-PDAC deaths are censored |
| `TAD` | 0/1 | 0 = non-TAD; 1 = TAD |
| `dm_group` | 0/1/2/3 | 0 = no DM; 1 = long-standing stable DM; 2 = new-onset DM; 3 = worsening DM |
| `stage` | 0/1 | 0 = ≤IIA; 1 = ≥IIB |
| `margin` | 0/1 | 0 = R0; 1 = R1 |
| `NLR` | 0/1 | 0 = <2.1; 1 = ≥2.1 |
| `NLR_raw` | numeric | Continuous neutrophil-to-lymphocyte ratio |
| `CA199` | 0/1 | 0 = ≤37; 1 = >37 U/mL |
| `CA199_raw` | numeric, >0 | Raw CA19-9 |
| `HbA1c` | numeric, % | Continuous preoperative HbA1c |
| `adj_chemo` | 0/1 | Adjuvant chemotherapy |
| `neoadj` | 0/1 | Neoadjuvant chemotherapy |
| `age` | numeric, years | Age at surgery |
| `CD4` | numeric, cells/mm² | Intratumoral CD4+ density |
| `CD8` | numeric, cells/mm² | Intratumoral CD8+ density |
| `FOXP3` | numeric, cells/mm² | Intratumoral FOXP3+ density |
| `CD45RO` | numeric, cells/mm² | Intratumoral CD45RO+ density |

Current cohort checks:

- total n = 162
- non-TAD/TAD = 98/64
- no DM/stable/new-onset/worsening = 81/17/40/24
- stage ≤IIa / ≥IIb = 43/119
- OS events = 120
- CSS events = 110
- stage ≤IIa: 24 OS events; 20 CSS events
- stage ≥IIb: 96 OS events; 90 CSS events
- neoadjuvant-excluded cohort = 144
- diabetes-only subset = 81

`CA199_raw` is analyzed as `log2(CA199_raw)` without an offset where a
continuous CA19-9 term is specified.

The survival models and immune-density models use different prespecified
covariate sets, as described in the manuscript Methods. Survival models use
pathologic stage, resection margin status, dichotomized NLR, and dichotomized
CA19-9 as the primary adjustment variables. The primary immune-density models
adjust for age, pathologic stage, log2-transformed CA19-9, continuous NLR, and
neoadjuvant chemotherapy.

## 2. `data/count_matrix.xlsx`

Used by `02_deseq2_differential_expression.R`.

First column: unique gene symbol.

Remaining 36 columns: raw integer read counts, one per organoid line.

TAD lines:

`KYK019, KYK020, KYK067, KYK084, KYK090, KYK093`

Sequencing platform:

- MiSeq: `KYK015`, `KYK019`
- HiSeq 2500: all remaining lines

Primary design:

`~ DM_group`

Sensitivity design:

`~ platform + DM_group`

Genes with row-summed raw count ≤10 are excluded.

Log2 fold changes are shrunken using `apeglm`. Differential expression is
defined using Benjamini-Hochberg-adjusted P < 0.05 without an additional
fold-change threshold.

PCA uses variance-stabilized counts from the **500 most variable genes**.

## 3. Primary DESeq2 output

Generated by `02_deseq2_differential_expression.R`:

`results/organoid_RNAseq/DESeq2_primary_all_results.xlsx`

Used by:

- `03_preranked_gsea.R`
- optionally `04_secreted_factor_tpm.py`

Key columns:

| Column | Definition |
|---|---|
| `SYMBOL` | Gene symbol |
| `baseMean` | Mean normalized count |
| `raw_log2FoldChange` | Unshrunken DESeq2 log2 fold change |
| `lfcSE_raw` | Standard error of the unshrunken estimate |
| `stat` | DESeq2 test statistic |
| `pvalue` | Nominal DESeq2 P value |
| `padj` | Benjamini-Hochberg-adjusted P value |
| `log2FoldChange` | `apeglm`-shrunken log2 fold change |
| `lfcSE_shrunken` | Standard error associated with the shrunken estimate |

The GSEA ranking statistic is:

`sign(log2FoldChange) * -log10(pvalue)`

The sign is derived from the shrunken log2 fold change, whereas the nominal
DESeq2 P value is retained for the ranking magnitude.

## 4. `data/organoid_expression_TPM.xlsx`

Used by `04_secreted_factor_tpm.py`.

Sheet:

`TPM`

Required columns:

- `gene_symbol`
- 36 sample columns ending in `_TPM`

The current sensitivity analysis evaluates the selected genes displayed in
Fig. 3e.

The comparison is performed using a two-sided Mann-Whitney U test on
`log2(TPM+1)` values. Because this is a strictly monotonic transformation, the
rank-test result is unchanged relative to analysis of the raw TPM values.

TPM-based P values are nominal and are not adjusted for multiple comparisons.

## 5. `data/organoid_driver_alterations.xlsx`

Used by `07_driver_gene_wgs_analysis.R`.

Required columns:

- `SampleID`
- `KRAS_any`
- `TP53_any`
- `CDKN2A_any`
- `SMAD4_any`

Each `*_any` column is a pre-derived 0/1 gene-level alteration call according to
the definitions in the manuscript Methods.

The current organoid cohort consists of:

- non-TAD: n = 30
- TAD: n = 6

The script performs two-sided Fisher's exact tests for the four major PDAC
driver genes. These comparisons are exploratory and P values are not adjusted
for multiple comparisons.

The underlying whole-genome sequencing data are available under controlled
access through EGA accession `EGAS00001007211`.

## 6. TCGA-PAAD public inputs

Used by `06_tcga_paad_analysis.R`.

Directory:

`data/TCGA/`

| File | Required content |
|---|---|
| `TCGA-PAAD.star_fpkm-uq.tsv.gz` | Ensembl-ID × TCGA-sample expression matrix |
| `TCGA-PAAD.clinical.tsv.gz` | `sample`, `primary_diagnosis.diagnoses` |
| `TCGA-PAAD.survival.tsv.gz` | `sample`, `OS`, `OS.time` |
| `gencode.v36.annotation.gtf.gene.probemap` | `id`, `gene` |
| `TCGA_mastercalls.abs_tables_JSedit.fixed.txt` | `array`, `call status`, `purity` |

Public-source metadata:

- UCSC Xena GDC Hub accessed 2026-04-28
- PanCanAtlas ABSOLUTE accessed 2026-07-31
- GDC UUID `4f277128-f793-4354-a13d-30cc7fe9f6b5`

The final expression cohort consists of 163 `-01A` primary tumors with
PDAC-compatible histology:

- infiltrating duct carcinoma, NOS: n = 143
- adenocarcinoma, NOS: n = 20

Additional cohort sizes:

- complete OS data: n = 162
- ABSOLUTE purity available: n = 143
- infiltrating duct carcinoma-only cohort: n = 143
- purity available in the duct-only cohort: n = 123

The Xena expression matrix used in the final workflow already contains the
log2-transformed FPKM-UQ values analyzed in the manuscript. Do **not** apply a
second `log2(x+1)` transformation.

GDF15 is dichotomized at the median of the n = 163 expression cohort.

Tumors with expression **at or above the median** are classified as
GDF15-high:

- expression cohort: Low n = 81 / High n = 82
- OS-evaluable cohort: Low n = 81 / High n = 81

The one tumor lacking complete survival information belongs to the GDF15-high
group.

The six TCGA transcriptomic outcomes are:

`CD8A, GZMA, GZMB, PRF1, CYT, DDIT3`

CYT is calculated as the arithmetic mean of the log2-scale GZMA and PRF1
expression values.

The current TCGA analyses include:

1. median-split comparisons of the six outcomes between GDF15-low and
   GDF15-high tumors, with Benjamini-Hochberg correction across all six tests;
2. continuous Spearman correlations between GDF15 and the same six outcomes;
3. partial Spearman correlations adjusted for ABSOLUTE tumor purity;
4. Benjamini-Hochberg correction across the six purity-adjusted correlations;
5. sensitivity analyses restricted to infiltrating duct carcinoma, NOS; and
6. Kaplan-Meier/log-rank analysis of overall survival according to
   median-dichotomized GDF15.

For the partial Spearman analyses, rank residualization is used. With `k`
adjustment covariates, the Fisher-z confidence-interval standard error is:

`1 / sqrt(n - k - 3)`

For the current purity-adjusted analysis, `k = 1`, giving:

`1 / sqrt(n - 4)`
