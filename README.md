Analysis scripts for the TAD-PDAC study

"[CURRENT MANUSCRIPT TITLE]"

The scripts document the statistical and bioinformatic workflows used for survival analyses, immunohistochemical analyses, differential gene expression analysis, gene set enrichment analysis, TCGA-PAAD transcriptomic analyses, ELISA quantification, and correlation analyses.

Patient-level clinical data are not publicly available because of patient privacy and ethical restrictions. Publicly available TCGA-PAAD data used in this study were obtained from the UCSC Xena GDC Hub. RNA-sequencing and whole-genome sequencing data generated in this study have been deposited in the European Genome-phenome Archive (EGA) under accession number EGAS00001007212.

Because patient-level clinical data and some locally generated intermediate files cannot be included in this repository, file paths, file names, and column names may need to be adapted to the local data structure according to the accompanying data dictionary.
